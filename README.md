# Robot Romance: One-Line Pickup Lines for AI

A single-line joke pickup line aimed at a robot / AI, for make.fun's **Robot Romance: One-Line Pickup Lines for AI** bounty. The program writes one line to `/output/entry.txt` — no network, no randomness, fully deterministic.

## The line

> Do you believe in love at first prompt, or should I hit regenerate and try again?

## Why it works

- **A pickup line aimed at a machine:** it opens like a classic "do you believe in love at first sight" line, but the object is a prompt — unmistakably addressed to an AI.
- **Setup + punch in one breath:** "love at first prompt" sets the premise, "hit regenerate and try again" lands the punch on the last beat.
- **Fresh premise:** no batteries, no charging, no reboot — the joke runs on the one thing you actually do with a chatbot: prompt, regenerate, retry.
- **Sounds said, not written:** "hit regenerate" is the exact verb a person uses with a chatbot, so the line reads like something someone would really say to a machine.
- **No wasted words:** every word earns its place; the punch arrives with nothing before it but the setup.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```
